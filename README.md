# Window Resizer

## 一个轻量级的 Windows 窗口控制工具。通过 PID 或鼠标点击拾取目标窗口，精准控制其尺寸与屏幕位置，支持永久置顶 / 一键置前 / 强制结束进程。

## 🎯 主要功能

### 🔍 拾取窗口
点击 **"拾取窗口"** 按钮，然后点击任意目标窗口，即可自动获取其 PID、宽高和当前位置。

### 📐 强制调整大小
输入目标宽度和高度，点击 **"强制调整大小"** 即可改变窗口尺寸。

> 💡 **初衷**：使用网易 UU 远程时，其视窗大小有下限，不利于摸鱼时观看视频/文档。这个小工具就是为了突破这个限制而生。

### 🧭 窗口定位（扩展功能）
通过 X/Y 滑块，手动调整窗口在屏幕上的位置。

> 💡 **适用场景**：当某个窗口因误操作飞出显示器可视范围时，可用此功能将其"拉"回来。

### 📌 窗口永久置顶（扩展功能）
拾取目标窗口后，点击 **"📌 窗口永久置顶"** 即可让窗口始终悬浮在其他窗口之上；再次点击同按钮可取消置顶。

> 💡 **按钮会随状态变化**：已置顶时按钮变为 **"取消置顶"**（绿色），方便识别当前状态。

> 💡 **适用场景**：摸鱼时将小窗视频固定在屏幕角落，切换窗口也不会被遮挡。

### ⬆ 置于最前面（扩展功能）
拾取目标窗口后，点击 **"⬆ 置于最前面"** 可立即将窗口调至最前端并获得焦点（仅调一次层级，不锁定）。

> 💡 **与"永久置顶"的区别**：本功能只是把窗口提到当前最前，之后其他窗口仍可正常覆盖它；而"永久置顶"会让窗口一直保持在最上层。

### ❌ 强制结束窗口（扩展功能）
拾取目标窗口后，点击 **"❌ 强制结束窗口"** 可直接终止该窗口对应的进程。

> ⚠️ **安全提示**：点击后会弹出二次确认对话框，防止误操作；操作不可撤销，未保存的数据将丢失。

> 💡 **适用场景**：远程窗口卡死无法关闭、进程无响应时，快速强制结束而不必打开任务管理器。

## 🚀 使用方法

### 方式一：直接运行 EXE（推荐）
下载 [Releases](https://github.com/Tigarcen/window-resizer/releases) 中的 `ForceResize.exe`，双击运行即可。无需安装任何环境。

### 方式二：运行 PowerShell 脚本
```powershell
.\ForceResize.ps1
```

### 构建为exe
```shell
ps2exe -InputFile ".\ForceResize.ps1" -OutputFile ".\ForceResize.exe" -RequireAdmin -NoConsole
```
